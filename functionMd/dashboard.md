## 3. 계산 규칙 (index.html 스크립트)
- 기준일 `DATA.baseDate`(2026-10-31). D-Day = 기한 − 기준일 → 지남 `D+n`(text-destructive), 0~2일 `text-warning`.
- 기한 초과 = 미완료 & 기한 < 기준일. 기한 임박 = 미완료 & 0 ≤ 남은 일수 ≤ 2.
- 적기처리율(부서원별·유형별) = 금월 완료 중 완료일 ≤ 기한 비율.
- 점검 필요 = 최종 점검 없음 또는 `inspectCycleDays`(180일) 경과. 내용연수 만료일 = 도입일 + 내용연수(년).
- 월간 지표는 `srMonthly`·`assetMonthly`·`portalMonthly` 이력값. 금월 행은 원장 집계와 일치시킨다.

## 4. 협의 필요
- 관리자 범위: 부서장 1단계 부서만인지, 하위 팀 포함인지
